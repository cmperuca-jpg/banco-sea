FUSION SISTEMA

Instale no celular ou no computador

Use a PWA para acessar pelo celular e o aplicativo Windows no computador que controla a operação local e a catraca.

Celular e tablet

Instala a PWA sem loja de aplicativos. Depois da instalação, o Fusion Sistema aparece na tela inicial.

  1. Abra esta página no Chrome ou Edge.
  2. Toque em Instalar PWA.
  3. Entre com o usuário da academia.
Abrir no navegador

Computador Windows

O instalador configura o sistema local, cria atalhos e inicia o Fusion Sistema junto com o Windows.

  1. Baixe o instalador.
  2. Execute FusionSistema-Setup.exe.
  3. Entre com e-mail e senha.
Baixar para Windows
O cliente final não precisa instalar Node.js nem configurar o Supabase.
